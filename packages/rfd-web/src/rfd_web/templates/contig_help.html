Contig Definition Help

The contigs string defines the regions of the protein structure that are fixed (taken from the input template) and the regions that are free (to be hallucinated/diffused by the model).

Syntax

  • Free segments (hallucinated): Specified by a single integer (e.g., 50) or a range (e.g., 10-50).
  • Fixed segments (from template): Specified by chain ID and residue range (e.g., A10-20) or just chain ID for the whole chain (e.g., A).
  • Chain breaks: Use /0 (zero and a space) to indicate a chain break. Note that internally RFdiffusion uses /0 but for the GUI we use spaces or slashes to separate blocks if they are distinct chains.

Examples

  • Unconditional generation (Hallucination):
    100
    Builds a 100-residue protein from scratch.
  • Motif Scaffolding (Inpainting):
    10-40/A10-25/10-40
    Builds a protein with 10-40 hallucinated residues, followed by residues 10-25 from chain A of the template, followed by 10-40 hallucinated residues.
  • Binder Design:
    A/10-100
    Uses all of chain A as a fixed target, and builds a 10-100 residue hallucinated binder against it.
